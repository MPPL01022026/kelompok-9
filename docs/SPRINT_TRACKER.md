# Sprint Tracker

Status berikut hanya menunjukkan artefak perencanaan yang tersedia di folder ini. Perbarui setelah pekerjaan atau review benar-benar dilakukan.

| Aktivitas | Output | PIC usulan | Status | Bukti |
|---|---|---|---|---|
| Project Charter | Dokumen charter | Nayla Salsabila Awika | Draft tersedia lokal | [Project Charter](sprint-01/PROJECT_CHARTER.md) |
| Stakeholder Register | Daftar pihak terkait | Nayla Salsabila Awika | Draft tersedia lokal | [Stakeholder Register](sprint-01/STAKEHOLDER_REGISTER.md) |
| WBS | Paket kerja proyek | Nayla Salsabila Awika, tim | Draft tersedia lokal | [WBS](sprint-01/WORK_BREAKDOWN_STRUCTURE.md) |
| Function Point | Estimasi awal | Tim | Ditranskripsikan dari brief; belum diverifikasi | [Function Point](sprint-01/FUNCTION_POINT.md) |
| Validasi kebutuhan | Catatan wawancara/observasi | Tim | Belum ada bukti tambahan | Menunggu kegiatan validasi |
| Repository dan kontribusi | Riwayat commit kelompok | Semua anggota | Repository kelompok belum ditautkan | Ikuti alur branch, commit identitas sendiri, dan Pull Request yang dijelaskan di README |
