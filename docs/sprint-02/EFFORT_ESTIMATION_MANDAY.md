# Effort Estimation (Manday) — Sprint 2

Estimasi berikut adalah baseline awal untuk perencanaan, bukan timesheet atau komitmen kapasitas. Satu manday berarti usaha satu orang selama satu hari kerja. Durasi kalender dapat berbeda karena pekerjaan paralel, dependensi, ketersediaan, dan waktu tunggu review.

| ID | Aktivitas | PIC estimasi | Estimasi (manday) | Dasar / asumsi |
|---|---|---|---:|---|
| S2-01 | Konfirmasi kebutuhan dan keputusan terbuka | Nayla, Niluh, tim | 2.0 | Sesi koordinasi dan pencatatan; bergantung pada ketersediaan pemilik |
| S2-02 | Spesifikasi kebutuhan, use case, dan alur | Niluh | 3.0 | Analisis brief dan penyusunan draft; Zahra meninjau alur |
| S2-03 | Wireframe halaman utama | Zahra | 3.0 | Rancangan awal halaman katalog, pemesanan, login/admin, dan laporan; Niluh review |
| S2-04 | Model data awal | Zahra | 2.0 | Entitas dan relasi inti dari kebutuhan yang tersedia; Faiza review kelayakan |
| S2-05 | Review arsitektur dan kesiapan rencana teknis | Faiza | 2.0 | Meninjau rencana stack dan dependensi; tidak termasuk setup atau implementasi |
| S2-06 | Review dokumen dan tindak lanjut | Nayla, tim | 1.5 | Konsolidasi feedback dan pencatatan keputusan |
| **Total awal** |  |  | **13.5** | Perbarui setelah PIC menilai ulang tugas dan kapasitas |

## Validasi estimasi

Setiap PIC meninjau estimasi aktivitasnya sebelum baseline disetujui. Catat nilai aktual setelah pekerjaan selesai agar estimasi berikutnya dapat diperbaiki. Estimasi ini tidak termasuk waktu tunggu pemilik/dosen, dan tidak menyatakan hari kalender tertentu.
